## 🎯 معرفی سریع

**RakeGlossary چیکار می‌کنه؟**

فرض کن یک کتاب انگلیسی داری و می‌خواهی واژه‌های مهمش را با ترجمه‌ی فارسی داشته باشی. RakeGlossary:

1. فایل کتاب را می‌گیرد (PDF، DOCX، EPUB، TXT)
2. واژه‌های مهمش را پیدا می‌کند
3. برای هر واژه تعریف می‌نویسد
4. تعریف و واژه را به فارسی ترجمه می‌کند
5. یک فایل CSV یا Excel به تو می‌دهد

**برای کی مفیده؟**
- مترجمانی که واژه‌نامه‌ی اختصاصی کتاب می‌خواهند
- ویراستارانی که به term base نیاز دارند
- دانشجویانی که می‌خواهند واژگان تخصصی یک کتاب را یاد بگیرند
- هرکسی که با متن‌های طولانی انگلیسی سر و کار دارد

## 📦 نصب و راه‌اندازی

### پیش‌نیازها

- **Windows 10 یا 11**
- **Python 3.12** نصب باشد
- **Node.js 20 یا بالاتر** نصب باشد

### نصب گام‌به‌گام

**گام ۱: دانلود پروژه**

پوشه‌ی RakeGlossary را در مسیری مثل `C:\projects\` بگذار.

**گام ۲: اجرای setup (فقط یک بار)**

پوشه‌ی `scripts` را باز کن و روی فایل `setup.bat` دابل‌کلیک کن.

یک پنجره‌ی cmd باز می‌شود و:
- venv می‌سازد
- همه‌ی پکیج‌های پایتون را نصب می‌کند
- مدل spaCy را دانلود می‌کند (~۱۲MB)
- داده‌های NLTK را دانلود می‌کند
- پکیج‌های npm را نصب می‌کند

**زمان:** ~۵-۱۰ دقیقه (بستگی به اینترنت دارد)

**گام ۳: اجرا**

از پوشه‌ی RakeGlossary، روی `scripts\dev.bat` دابل‌کلیک کن.

دو پنجره باز می‌شود:
- پنجره‌ی Backend (سفید با متن زیاد)
- پنجره‌ی Frontend (با `VITE ready`)

**گام ۴: باز کردن مرورگر**

مرورگر را باز کن و برو به:

```
http://localhost:5173
```

**نکته:** پنجره‌های Backend و Frontend را نبند. اگر ببندی، برنامه کار نمی‌کند.

### پایان کار

هر دو پنجره را ببند. تمام.

### اجرای دفعه‌ی بعد

فقط `scripts\dev.bat` را دابل‌کلیک کن. `setup` فقط یک بار لازم است.

## 🚀 ساخت اولین پروژه

### گام ۱: صفحه‌ی خانه

در صفحه‌ی خانه (`/`)، این فیلدها را می‌بینی:

**الف) عنوان پروژه**

یک نام دلخواه برای پروژه. مثلاً:
- «کتاب فیزیک هالیدی»
- «رمان کافکا در کرانه»
- «مقاله یادگیری ماشین»

**ب) منبع متن — دو تب داری:**

**تب «آپلود فایل»:**
- می‌توانی چند فایل را همزمان Drag & Drop کنی
- پشتیبانی: PDF، DOCX، EPUB، TXT
- می‌توانی بعداً فایل بیشتری از صفحه‌ی پروژه اضافه کنی

**تب «ورود متن»:**
- برای متن‌های کوتاه یا کپی‌شده
- نام متن (مثلاً «فصل ۱»)
- متن را در Textarea پیست کن
- تعداد کلمات زنده نمایش داده می‌شود

**ج) اطلاعات کتاب (اختیاری ولی خیلی مفید)**

پنل «اطلاعات کتاب» را باز کن. فیلدهای مهم:
- **ژانر اصلی:** رمان؟ علمی؟ تاریخی؟
- **تم‌های اصلی:** هویت؟ تنهایی؟ عشق؟
- **مخاطب هدف:** بزرگسالان؟ نوجوانان؟
- **زمینه فرهنگی:** ارجاعات خاص کتاب

این اطلاعات به LLM می‌گوید «این کتاب درباره چیه» تا واژه‌های بهتری انتخاب کند.

**د) دکمه‌ی «ایجاد و شروع پردازش»**

اگر منبع را وارد کرده باشی، این دکمه فعال است. کلیک کن.

### گام ۲: صفحه‌ی پروژه

بعد از کلیک، به صفحه‌ی پروژه منتقل می‌شوی.

**اگر منبع نداده بودی:** الان از این صفحه می‌توانی **افزودن منبع** بزنی.

## 📚 اطلاعات کتاب (مهم)

اطلاعات کتاب فقط یک فرم تزئینی نیست. **مستقیماً روی کیفیت خروجی اثر می‌گذارد.**

### چرا مهم است؟

فرض کن LLM می‌خواهد `Nakata` را ترجمه کند.

**بدون اطلاعات کتاب:**
- ترجمه می‌کند: «ناکاتا» یا «نکاتا» یا «ناکتا» (متغیر)

**با اطلاعات کتاب:**
```
Title: Kafka on the Shore
Author: Haruki Murakami
Setting: Japan, contemporary
```
- ترجمه می‌کند: «ناکاتا» (استاندارد و ثابت)

### فیلدهای مهم کدام‌اند؟

| فیلد | اثر |
|---|---|
| **ژانر اصلی** | LLM می‌داند چه اصطلاحاتی مهم‌ترند |
| **تم‌های اصلی** | تمرکز LLM روی واژه‌های مرتبط |
| **دوره زمانی** | واژه‌های همان دوره بهتر استخراج می‌شوند |
| **مکان** | ترجمه‌ی درست اسامی مکان‌ها |
| **زمینه فرهنگی** | ترجمه‌ی درست ارجاعات فرهنگی |

### کجا وارد کنم؟

دو راه داری:

**راه ۱: فرم دستی**

در صفحه‌ی خانه یا صفحه‌ی پروژه، پنل «اطلاعات کتاب» را باز کن و فیلدها را پر کن.

**قانون مهم:** همه‌ی فیلدها باید **انگلیسی** باشند. کد فقط حروف لاتین قبول می‌کند.

**راه ۲: آپلود فایل JSON**

اگر یک سیستم دیگر (مثلاً یک ابزار استخراج اطلاعات) فایل JSON برایت ساخته، در تب «آپلود JSON» آن را بیاور. ساختار باید مثل `BookSpecsTemplate.json` باشد.

### فیلد «اصطلاحات کلیدی»

این فیلد خاص است. اگر می‌دانی بعضی اصطلاحات باید در واژه‌نامه باشند و ترجمه‌ی مشخصی دارند، این‌طور وارد کن:

```
Nakata=ناکاتا
café=کافه
karma=کارما
the Force=نیرو
```

**قوانین مهم:**
- **بدون فاصله** اطراف `=`
- برای جفت بعدی، **Enter** بزن
- term باید انگلیسی باشد
- ترجمه اختیاری است (اگر نباشد، LLM خودش تصمیم می‌گیرد)

**نتیجه:** LLM مجبور می‌شود این ترجمه‌ها را دقیقاً همان‌طور که تو نوشتی استفاده کند. این برای consistency ضروری است.

## 🎯 انتخاب حالت پردازش

سه حالت داری:

### حالت Offline (رایگان و سریع)

```
تعریف: در متن → Wikipedia → WordNet
ترجمه: Argos (کاملاً آفلاین روی سیستم)
هزینه: صفر
```

**مناسب برای:**
- می‌خواهی سریع نتیجه بگیری
- به اینترنت وصل نیستی
- هزینه مهم است
- کیفیت ترجمه‌ی Argos برایت کافی است

**معایب:**
- ترجمه‌ی Argos گاهی برای متن‌های ادبی ضعیف است
- تعاریف Wikipedia گاهی خیلی فنی هستند

### حالت Hybrid (ترکیبی)

```
تعریف: در متن → Wikipedia → WordNet (رایگان)
ترجمه: LLM (با درک زمینه‌ی کتاب)
هزینه: ~نصف AI
```

**مناسب برای:**
- کیفیت ترجمه‌ی بالاتر می‌خواهی
- ولی نمی‌خواهی هزینه‌ی کامل AI را بدهی
- کلید API داری

### حالت AI (بهترین کیفیت)

```
تعریف: LLM
ترجمه: LLM
هزینه: ~$0.01 per 100 terms
```

**مناسب برای:**
- بهترین کیفیت ممکن مهم است
- کلید API داری
- هزینه اشکالی ندارد

**نکته:** در حالت AI، همه چیز با LLM انجام می‌شود. برای رسیدن به target count، متن به چانک‌های ۲۵۰۰ کلمه‌ای تقسیم می‌شود.

### کدام را انتخاب کنم؟

اگر اولین بار است استفاده می‌کنی:
1. با **Offline** شروع کن
2. نتیجه را ببین
3. اگر ترجمه‌ها باب میلت نبود، **Hybrid** یا **AI** امتحان کن

## ⚙️ تنظیمات پیشرفته

### چگالی واژگان (terms per 1000 words)

مشخص می‌کند «هر ۱۰۰۰ کلمه‌ی متن، چند واژه استخراج شود».

**مثال:**
- کتاب ۲۰٬۰۰۰ کلمه
- چگالی = ۱۵
- نتیجه: ۲۰ × ۱۵ = ۳۰۰ واژه

**مقدار پیش‌فرض:** ۱۵

**اگر بیشتر می‌خواهی:** ۲۰-۲۵ (شلوغ‌تر می‌شود)
**اگر کمتر می‌خواهی:** ۵-۱۰ (فقط واژه‌های خیلی مهم)

### حداکثر کل واژه‌ها (max terms)

سقف نهایی. اگر چگالی عدد بزرگ‌تری بدهد، این سقف اعمال می‌شود.

**مثال:**
- کتاب ۲۰٬۰۰۰ کلمه × چگالی ۲۵ = ۵۰۰ واژه
- max_terms = ۳۰۰
- نتیجه: ۳۰۰ واژه

### ترجمه

- **ترجمه عبارات کلیدی:** اگر خاموش شود، فقط term انگلیسی استخراج می‌شود، ستون فارسی خالی می‌ماند.
- **ترجمه تعاریف:** اگر خاموش شود، تعریف انگلیسی می‌ماند ولی ترجمه نمی‌شود. برای صرفه‌جویی در هزینه مفید است.

### NLP (فقط Offline و Hybrid)

روش‌های استخراج واژه:

- **spaCy (Noun Chunks):** عبارات اسمی استخراج می‌کند. پایه‌ی اصلی.
- **RAKE (co-occurrence):** واژه‌های هم‌رخداد را پیدا می‌کند.
- **YAKE (unsupervised):** extraction آماری بدون آموزش.
- **spaCy NER (اسامی خاص):** اشخاص، مکان‌ها، سازمان‌ها.

**پیشنهاد:** همه را روشن بگذار (مگر سرعت مهم باشد).

## ✏️ ویرایش واژه‌نامه

بعد از پردازش، جدول نتایج را می‌بینی. این جدول ۹ ستون دارد:

| ستون | توضیح |
|---|---|
| **#** | شماره ردیف |
| **English Term** | واژه‌ی انگلیسی |
| **Persian Term** | ترجمه‌ی فارسی |
| **Context** | جمله‌ای از متن که واژه در آن آمده |
| **Persian Definition** | توضیح فارسی (اختیاری) |
| **Source** | منبع تعریف (Wikipedia / WordNet / In-Text / LLM / None) |
| **Score** | امتیاز اهمیت (۰ تا ۱) |
| **Freq** | تعداد دفعات تکرار در متن |
| **عملیات** | 🚫 (blacklist) و 🗑️ (حذف) |

### ویرایش سلول

1. روی هر سلول کلیک کن → editable می‌شود
2. تایپ کن
3. **Enter** = ذخیره
4. **Esc** = لغو

### دکمه‌ی 🚫 (Blacklist)

وقتی روی یک واژه کلیک می‌کنی:
1. دیالوگ تأیید ظاهر می‌شود
2. اگر تأیید کنی:
   - واژه از این پروژه حذف می‌شود
   - **واژه به لیست سیاهه اضافه می‌شود** (یعنی دیگر در هیچ پروژه‌ای استخراج نمی‌شود)

**کِی استفاده کنم؟** وقتی واژه‌ی بی‌ارزش است (مثل `the`, `however`, `chapter`).

### دکمه‌ی 🗑️ (حذف)

فقط از این پروژه حذف می‌کند. در سایر پروژه‌ها باقی می‌ماند.

### Tooltip ها

روی بعضی هدرها و آیکون‌ها hover کن، توضیح می‌بینی:
- **Context ⓘ:** توضیح context
- **Source ⓘ:** توضیح منبع
- **Score ⓘ:** نحوه‌ی محاسبه
- **badge Source:** توضیح دقیق منبع

## 🚫 کلمات سیاهه

### کجاست؟

`/settings` → پایین صفحه → **کلمات سیاهه**

### چیکار می‌کند؟

لیستی از کلمات که **هرگز** در هیچ پروژه‌ای استخراج نمی‌شوند.

### چطور اضافه کنم؟

1. در input، کلمه را انگلیسی تایپ کن (فقط حروف لاتین)
2. **افزودن** یا **Enter**
3. chip کلمه ظاهر می‌شود

### مثال‌های مفید

```
the
however
chapter
page
figure
table
```

### چطور حذف کنم؟

روی آیکون 🗑️ کنار chip کلیک کن.

### نکته

**این لیست سراسری است** — یعنی اگر `the` را اضافه کنی، در همه‌ی پروژه‌ها حذف می‌شود.

## 🤖 تنظیم LLM (هوش مصنوعی)

### کجا؟

`/settings` → بخش **هوش مصنوعی (LLM)**

### گام ۱: فعال کردن

سوئیچ **فعال** را روشن کن.

### گام ۲: انتخاب Provider

از dropdown انتخاب کن:

| Provider | مناسب برای |
|---|---|
| **OpenAI** | بهترین کیفیت، معروف |
| **OpenRouter** | دسترسی به مدل‌های مختلف (Claude, Gemini, ...) |
| **Google Gemini** | رایگان‌تر، سریع |
| **GapGPT** | دسترسی آسان از ایران |
| **DeepSeek** | ارزان و باکیفیت |
| **Groq** | خیلی سریع (Llama) |
| **Custom** | هر سرویس سازگار با OpenAI |

### گام ۳: کلید API

روی **دریافت کلید API** کلیک کن → به سایت provider می‌روی → ثبت‌نام → کلید بساز → در input پیست کن.

**کِی استفاده کنم؟** کلید ذخیره می‌شود ولی فقط بعد از ذخیره، mask نمایش داده می‌شود.

### گام ۴: انتخاب مدل

مدل پیش‌فرض هر provider به‌صورت خودکار پر می‌شود. می‌توانی از لیست پیشنهادی انتخاب کنی یا دستی تایپ کنی.

### گام ۵: تست اتصال

روی **تست اتصال** کلیک کن. اگر موفق شد، پیام سبز با latency می‌بینی. اگر خطا داد، متن خطا را بخوان.

### گام ۶: ذخیره

روی **ذخیره** کلیک کن. Toast سبز ظاهر می‌شود.

### انتخاب حالت AI یا Hybrid

از این به بعد، در OptionsPanel پروژه، می‌توانی **AI** یا **Hybrid** انتخاب کنی.

## 📦 خروجی گرفتن

### سه فرمت داری

**۱. CSV (دوستونه)**

فقط two-column:
```csv
English Term,Persian Term
Yumiko,یومیکو
```

مناسب برای: import سریع در ابزارها.

**۲. XLSX (۱۳ ستون)**

فایل Excel با همه‌ی اطلاعات. مناسب برای ویرایش دستی.

**۳. TBX (استاندارد ISO)**

فایل XML. مناسب برای ابزارهای CAT مثل memoQ و SDL Trados.

### چطور دانلود کنم؟

در صفحه‌ی پروژه، بالای جدول، سه دکمه می‌بینی:
- **CSV**
- **Excel**
- **TBX**

روی هرکدام کلیک کن → فایل دانلود می‌شود.

**نام فایل:** `{عنوان پروژه}_{id کوتاه}.{پسوند}`

## ❓ سوالات پرتکرار

**Q: چرا بعضی ترجمه‌ها `(ترجمه نشده)` هستند؟**
A: Google Translate یا LLM در آن لحظه خطا داده. می‌توانی دستی ویرایش کنی یا دوباره Re-process کنی.

**Q: چرا بعضی Context ها خالی (`—`) هستند؟**
A: LLM context برنگردانده و regex هم در متن پیدا نکرده. اگر واژه واقعاً در متن نیست، یعنی LLM آن را از خودش ساخته.

**Q: فایل‌های آپلودشده کجا هستند؟**
A: در `data/projects/{عنوان}_{id}/`. می‌توانی در File Explorer باز کنی.

**Q: چرا Processing طول می‌کشد؟**
A: در حالت AI یا Hybrid، هر واژه یک call به LLM می‌فرستد. برای ۱۰۰ واژه، ۱-۲ دقیقه طبیعی است.

**Q: چرا تعداد واژه‌های استخراج‌شده کمتر از حد انتظار است؟**
A: LLM ممکن است محافظه‌کار باشد. می‌توانی چگالی را بالا ببری یا prompt سخت‌گیرانه‌تر استفاده کنی.

**Q: چطور می‌توانم پردازش را متوقف کنم؟**
A: در حین پردازش، دکمه‌ی **Stop** ظاهر می‌شود. کلیک کن → تأیید.

**Q: چرا در حالت AI، Persian Definition خالی است؟**
A: در حالت AI، تعاریف ترجمه نمی‌شوند (به خاطر هزینه). اگر می‌خواهی ترجمه شوند، حالت Hybrid یا Offline را انتخاب کن.

**Q: کلید API را گم کرده‌ام. چطور پاک کنم؟**
A: `/settings` → LLM → **پاک کردن**. یا فقط provider را عوض کن، خودکار پاک می‌شود.

## 🔧 عیب‌یابی

### Backend بالا نمی‌آید

**خطا:** `Port 8765 is already in use`

**راه‌حل:** یک پنجره‌ی backend دیگر باز است. آن را ببند یا:

```cmd
Get-Process python | Stop-Process -Force
```

سپس دوباره `scripts\dev-backend.bat`.

### Frontend بالا نمی‌آید

**خطا:** `Port 5173 is already in use`

**راه‌حل:** همان کار بالا برای port 5173.

### خطای `openai not found`

**راه‌حل:** در پنجره‌ی backend:

```cmd
cd C:\projects\Translation\RAKE
.\venv312\Scripts\activate.ps1
pip install openai
```

### ترجمه‌ها خالی هستند

**علت:** Google Translate rate limit خورده یا LLM خطا داده.

**راه‌حل:**
- در حالت Offline: مطمئن شو Argos نصب است.
- در حالت AI/Hybrid: کلید API را چک کن و VPN اگر لازم است.

### فایل‌ها آپلود نمی‌شوند

**علت:** فرمت پشتیبانی‌نشده یا حجم زیاد.

**راه‌حل:** فرمت باید PDF/DOCX/EPUB/TXT باشد. حجم حداکثر ۲۰۰ مگابایت.
